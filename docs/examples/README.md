# Примеры формы ответов
Это синтетические фикстуры для разработки UI и контракта. ID EV_SYS/EV_TALK отсутствуют в официальном каталоге.
Не отправлять эти event IDs в API с официальным датасетом и не показывать фикстуры как реальное демо.
completion.json, import.json, hr.json описывают ЦЕЛЕВОЙ контракт: эти три маршрута в starter ещё возвращают 501.
Реальные записи/ID frontend получает из живых API. Форматы импортируемых собственных тестов — ../jury_examples/.
