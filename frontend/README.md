# Интерфейс Career Quest

Vue 3 + Vite, RU / KK / EN. Рабочее приложение находится только в frontend/.

## Возможности

Профиль, рекомендации с факторами, независимый прогноз шага, завершение активности, каталог, HR-сводка и импорт JSON/CSV. Все навыки, прогресс и рекомендации приходят из API. Встроенного датасета и локального расчёта прогресса нет.

Токен и данные сессии хранятся в памяти вкладки; в localStorage — только язык. Повтор завершения использует исходный UUID. Устаревшие ответы и несовпадающие версии не отображаются как актуальные.

## Запуск

Из корня: `python start.py`. Подробности и токены — в [общем README](../README.md).

## Проверки

`npm --prefix frontend test` — 41 тест. `npm --prefix frontend run build` — production-сборка. `npm --prefix frontend run test:live` — настоящий API с временной базой (переменные DATA_DIR и CQ_PYTHON описаны в README). Итоговый отчёт: [VALIDATION](../docs/VALIDATION.md).
