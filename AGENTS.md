# Career Quest — правила для coding agents

Перед изменениями прочитай docs/START_HERE.md, CONTEXT.md, docs/API_CONTRACT.md и файл своей роли в prompts/.
Команда сейчас работает в одном общем каталоге main. Упоминания отдельных веток в старых заданиях не применяются.
Не считай этот starter готовым MVP. Полный статус находится в README.md.

- Сначала проверь git status и текущую ветку. Не удаляй и не перезаписывай существующую работу.
- Backend: backend/**, tests/test_api.py, tests/test_domain.py, scripts/**.
- AI: ai/**, tests/test_ai.py, дополнительные AI-тесты.
- Frontend: frontend/**.
- shared/contracts.py, URL/JSON, зависимости и корневые документы меняются только согласованно.
- Не реорганизовывай весь репозиторий ради своей части. Используй адаптер для существующего кода.
- Не делай merge, push, git reset --hard, force-push, удаление веток или секретов без прямого поручения.
- Не коммить .env, API-ключи, .local/, node_modules, .venv или исходные данные в публичный репозиторий.
- Не трогай тесты чужой зоны. Единственное исключение для Дамира: заменить starter-тесты 501
  реальными acceptance-тестами по мере реализации соответствующих маршрутов.
- После работы запусти профильные тесты и сообщи: файлы, команды, результаты, ограничения.
- Не называй fallback AI-ответом. Не выдумывай активности, прирост навыков, грейды или результаты тестов.
